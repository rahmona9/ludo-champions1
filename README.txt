لودو الأبطال - مشروع أندرويد
============================
الطريقة 1 (Android Studio):
  1) افتح المجلد LudoChampions في Android Studio وانتظر Sync.
  2) Build > Build APK(s). الملف يطلع في app/build/outputs/apk/debug/app-debug.apk

الطريقة 2 (بدون Android Studio، عبر GitHub):
  1) اعمل مستودع جديد في GitHub وارفع كل محتويات هذا المجلد (مع .github).
  2) ادخل تبويب Actions > Build APK > Run workflow.
  3) بعد دقيقتين تنزّل الملف من Artifacts: LudoChampions-apk.

الطريقة 3: ملف index.html داخل app/src/main/assets هو اللعبة كاملة، وتقدر تفتحه في أي متصفح.
